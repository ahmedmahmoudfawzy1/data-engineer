02 / Curriculum

8 modules, one connected stack

Each module builds on the last. You start in the terminal and finish with a dashboard sitting on top of your own warehouse and lakehouse.

  1. 01
    Weeks 1–2

    Foundations: DE Concepts, CLI & Git

    The data engineering role and lifecycle, ETL vs ELT, OLTP vs OLAP, the Linux/WSL command line, Git and GitHub collaboration, and file formats (CSV, JSON, Parquet).

    By the endWork in a Linux shell, use Git/GitHub with pull requests, and explain the data lifecycle.

    • WSL2
    • Git
    • GitHub
    • VS Code
  2. 02
    Weeks 3–7Mini-Project 1

    Python for Data Engineering

    Syntax and data structures, functions, files, errors and logging, packages and venv, OOP and clean code, pandas, APIs and pytest.

    By the endWrite tested, logged Python scripts that extract from an API, transform with pandas and save Parquet.

    • Python
    • pandas
    • pytest
    • requests
  3. 03
    Weeks 7–11Mini-Project 2

    SQL & Relational Databases (T-SQL)

    SELECT, filtering, joins, aggregation, subqueries, CTEs, window functions, DDL/DML, transactions, indexes and stored procedures.

    By the endWrite complex analytical T-SQL, create schemas and read execution plans.

    • SQL Server
    • SSMS
  4. 04
    Weeks 11–13Capstone Milestone 1

    Data Modeling & Warehousing

    Normalisation, ER modeling, dimensional modeling, star schema, SCD types, fact types, warehouse layers, and DW vs lake vs lakehouse.

    By the endDesign a star schema from business questions and document source-to-target mappings.

    • SQL Server
    • draw.io
  5. 05
    Weeks 13–15Mini-Project 3

    ETL with SSIS

    SSIS architecture, data flow transformations, control flow, variables and parameters, dimension and fact loading, incremental loads, deployment and scheduling.

    By the endBuild, deploy and schedule SSIS packages that load a dimensional warehouse incrementally.

    • Visual Studio
    • SSIS
    • SQL Server Agent
  6. 06
    Weeks 16–20Mini-Project 4

    Spark & Databricks Lakehouse

    Spark architecture, DataFrames, Spark SQL, performance basics, Delta Lake, MERGE, the medallion architecture, Unity Catalog, Jobs and data quality.

    By the endBuild and schedule a bronze/silver/gold Delta pipeline with quality checks.

    • PySpark
    • Delta Lake
    • Databricks
  7. 07
    Weeks 21–23Mini-Project 5

    Orchestration with Apache Airflow

    Orchestration concepts, DAGs, operators, TaskFlow, scheduling, retries, sensors, Databricks integration, and monitoring and testing DAGs.

    By the endOrchestrate Python, Databricks and SQL Server tasks with reliable, tested DAGs.

    • Apache Airflow
    • WSL2
  8. 08
    Weeks 23–25Capstone dashboard

    Business Intelligence (Power BI)

    BI concepts, Power Query, semantic modeling, DAX, dashboard design, publishing, row-level security and performance.

    By the endBuild a modeled, secured, interactive dashboard on top of the warehouse and the lakehouse.

    • Power BI Desktop

API-to-Parquet ETL

A city mobility start-up wants daily weather data to study how weather affects trips. You extract hourly weather for 5+ cities from the Open-Meteo API, clean it with pandas and save a partitioned Parquet dataset, with logging and pytest tests.

SQL Analytics Case Study

  • SQL Server
  • SSMS

Warehouse Load with SSIS

An online retailer needs its order data loaded nightly into a star-schema warehouse. You design the schema, load SCD1/SCD2 dimensions and a fact table incrementally, then deploy to SSISDB and schedule it with SQL Server Agent.

Medallion Lakehouse Pipeline

What the capstone covers

  • Relational data warehouse in SQL Server, loaded by SSIS with SCD2 and incremental loads
  • Databricks lakehouse with bronze, silver and gold layers and idempotent MERGE
  • Data-quality checks, quarantine, and reconciliation between warehouse and lakehouse
  • Apache Airflow DAG with retries, sensors and branching, plus tests
  • Power BI dashboard over the warehouse and gold tables, with row-level security
  • GitHub repository with README, architecture diagram, source-to-target mapping, runbook and data dictionary
  • Final 15-minute demo followed by Q&A
